# Answer Engine Optimization (AEO)

## Snippet & Answer Guidelines
1. **Paragraph Snippets**: Direct answer in the first 40–55 words immediately below the section heading. Use definitional phrasing ("X is...").
2. **List Snippets**: Clean 5–9 item ordered or unordered lists for processes or feature sets.
3. **Table Snippets**: Multi-column comparison tables with clear header rows.
4. **Question-Phrased Headings**: Use natural-language questions for `<h2>` or `<h3>` (e.g., "What technologies power Invictus?", "How does OptiTrade calculate real-time metrics?").
5. **Knowledge Graph Entities**: Provide `sameAs` links to verified public profiles.

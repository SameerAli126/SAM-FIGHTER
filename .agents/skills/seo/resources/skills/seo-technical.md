# Technical SEO

## Technical Requirements
1. **Robots.txt**: Explicitly declare crawl policies for search crawlers (Googlebot, Bingbot) and modern AI agents (GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot).
2. **Sitemaps**: Include canonical URLs, lastmod timestamps, change frequencies, priorities, and alternate hreflang tags.
3. **Canonical URLs**: Prevent duplicate content with canonical links pointing to authoritative URLs.
4. **Landmark Regions**: Use accessible HTML5 landmarks (`header`, `nav`, `main`, `footer`, `article`, `section`) with ARIA labels.
5. **Security & Performance**: Strict HTTPS, security headers, optimized media, and sub-second paint times.

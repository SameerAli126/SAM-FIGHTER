# Schema.org Structured Data Graphs

## Core Entities
- **`Person`**: Name, alternate names, job title, worksFor, alumniOf, knowsAbout, sameAs, hasOccupation, contact points.
- **`WebSite`**: Name, URL, inLanguage, publisher.
- **`ProfilePage`**: WebPage subclass designating personal professional profile.
- **`SoftwareApplication`**: Name, description, operatingSystem, applicationCategory, author, offers.
- **`ItemList`**: Ordered list of projects with position indices.
- **`BreadcrumbList`**: Hierarchical breadcrumb navigation elements.
- **`TechArticle`**: Deep-dive technical documentation and case study metadata.
- **`OccupationalExperienceRequirements`**: Verifiable career experience requirements and months of experience.
